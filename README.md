### Proyectos Principales

</div>

<br>

#### 🎧 [Downloader-Nuclear](https://github.com/VicenteRC-Dev/Downloader-Nuclear)

Herramienta completa diseñada para **Nuclear Music Player**.  
Funciona como un **proxy + interfaz web** que captura la cola de reproducción en tiempo real, resuelve álbumes completos utilizando **yt-dlp**, permite cambiar fuentes de YouTube y descarga archivos MP3 en alta calidad (320 kbps) con carátula embebida, tags ID3 y organización automática por carpetas de álbum.

**Características principales:**
- Vigilante automático cada 5 segundos
- Resolución de álbumes completos o parciales
- Regeneración de streams caducados
- Cancelación de descargas en curso
- Acceso desde la red local (LAN)
- Temas de interfaz (Spotify, Apple Music, Lite)

**Stack:** Node.js · yt-dlp · FFmpeg

<br>

#### 🎵 [downloader-music-spotify](https://github.com/VicenteRC-Dev/downloader-music-spotify)

Herramienta orientada a la **descarga de canciones mediante interceptación de tráfico**.  
Permite capturar y descargar música de Spotify a través de técnicas de interceptación, con interfaz gráfica y soporte multiplataforma.

**Stack:** Python · Bash · JavaScript

<br>

#### 🔍 [Check-subdomains](https://github.com/VicenteRC-Dev/Check-subdomains)

Script de **enumeración y verificación de subdominios**.  
Lee una lista de subdominios desde un archivo de texto (`sub.txt`) y realiza comprobaciones para identificar cuáles se encuentran activos. Ideal para tareas de reconocimiento y análisis de superficie de ataque.

**Stack:** Python
